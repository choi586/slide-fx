발표용 통합 프롬프트

16:9 전체 화면 HTML 프레젠테이션을 제작해 줘. 방향키로 슬라이드를 전환하고 Space 또는 클릭으로 단계별 정보 공개를 진행하게 해 줘. 제목은 Blur Reveal, 프로세스 노드는 Stagger Animation, 연결선은 SVG Path Drawing, 화살표 위의 빛은 Animated Beam으로 표현해 줘. 빛 도착 후 Node Activation을 적용하고 마지막 성과 수치는 Count Up으로 표시해 줘. 발표용 본문은 충분히 크게 배치하고 데이터의 실제 값과 단위를 유지해 줘. 전환은 400~700ms, 정보 등장 효과는 300~600ms, 숫자는 1~1.5초를 기본으로 하며 필요한 곳에만 애니메이션을 사용해 줘. 슬라이드 재진입 시 재생할 수 있고 정지 버튼, prefers-reduced-motion 대응, 키보드 조작을 제공해 줘. 외부 CDN 없이 실행되는 단일 HTML로 만들어 줘.

구현 힌트: CSS Keyframes(빛·등장), SVG(경로·도형), Canvas(입자), GSAP(정교한 타이밍), D3.js / ECharts(차트·관계망), Reveal.js(프레젠테이션). 효과 이름은 일반 디자인 용어와 구현 방식이 혼합되어 있습니다.

예시 사진: NASA / STScI, Hubble eXtreme Deep Field 및 SpaceX, DSCOVR Falcon 9 launch (scikit-image 샘플 데이터, 공개 사용 가능). 사진 출처 및 이용 안내. 나머지 시각 예시는 이 사전을 위해 직접 만든 그래픽입니다. 데모는 효과 원리를 보여 주는 축약형으로 실제 발표에서는 사용자 데이터와 디자인에 맞게 조정하세요.
